# Submission checklist

[Course home](../README.md)

Complete Parts 1–6 in your `is117-web-server` folder. The `learn/...` branches are completed examples for comparison.

Before submitting:

- Restore the intentional bugs from Part 6. `npm test` should show **three passing tests**.
- Run `npm start` and check `/`, `/about`, and `/missing-page`. Stop the server with **Ctrl+C** afterward.
- Submit `index.js`, `package.json`, `package-lock.json`, `.gitignore`, and `tests/server.test.js` using your instructor's submission instructions. Leave out `node_modules` and the reference clone.

The `/hello` route and fourth test are optional. If you keep them, expect **four passing tests**, including the original three. No separate learning log, screenshots, or written report are required by these lessons.
