# Part 1: Node and the terminal

This is the **completed worked example** for Part 1 of IS117's first web server textbook. The current branch is `learn/01-node-and-terminal`.

**Checkpoint:** Print a message with node index.js.

## Read, then build

Start with [this part's lesson](docs/lessons/01-node-and-terminal.md). It explains the commands, code, expected output, and practice steps. Build the lesson in your own `is117-web-server` folder; use this separate `is117-reference` clone to compare completed work.

Begin with Node.js, npm, an editor, and a terminal. This branch has no npm project or web server yet.

## Run this reference

Install the tools using [setup](docs/setup.md). Open a terminal in this repository folder, then run these commands one at a time:

```bash
node index.js
```

`Hello, IS117! Node.js is running.` prints in the terminal, then the program finishes.

There are no Jest tests at this checkpoint; testing begins in Part 5.
